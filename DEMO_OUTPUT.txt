========== TRACING - THEO DẤU THỰC THI ==========

🎯 Ví dụ: Tính giai thừa của một số

Chương trình mẫu:
```
func factorial(n int) int {
    result := 1              // Line 1
    for i := 1; i <= n; i++ {  // Line 2
        result = result * i    // Line 3
    }
    return result            // Line 4
}
```

▶ Chạy: factorial(5)

📝 TRACE - THEO DẤU THỰC THI:
+------+---------------------------------------------+------------------------+
| Dòng | Câu lệnh                                    | Biến                   |
+------+---------------------------------------------+------------------------+
|    1 | result := 1                                 | n=5, result=1          |
|    2 | for i := 1; i <= 5                         | i=1, n=5, result=1     |
|    3 | result = 1 * 1 = 1                         | i=1, result=1          |
|    2 | for i := 2; i <= 5                         | i=2, n=5, result=1     |
|    3 | result = 1 * 2 = 2                         | i=2, result=2          |
|    2 | for i := 3; i <= 5                         | i=3, n=5, result=2     |
|    3 | result = 2 * 3 = 6                         | i=3, result=6          |
|    2 | for i := 4; i <= 5                         | i=4, n=5, result=6     |
|    3 | result = 6 * 4 = 24                        | i=4, result=24         |
|    2 | for i := 5; i <= 5                         | i=5, n=5, result=24    |
|    3 | result = 24 * 5 = 120                      | i=5, result=120        |
|    4 | return 120                                  | result=120             |
+------+---------------------------------------------+------------------------+

Tổng số câu lệnh đã thực thi: 12

📊 Phân tích:
- Tracing cho phép theo dõi toàn bộ quá trình thực thi
- Mỗi bước thực thi được ghi lại với giá trị biến tại thời điểm đó
- Hữu ích cho việc debug và hiểu luồng thực thi

========== DYNAMIC SLICING - CẮT ĐỘNG ==========

🎯 Ví dụ: Tính tổng và tích của dãy số

Chương trình mẫu:
```
 1: sum := 0
 2: product := 1
 3: for i := 1; i <= 5; i++ {
 4:     sum = sum + i
 5:     product = product * i
 6: }
 7: result := sum + product
 8: print(result)
```

▶ Thực thi chương trình:
  Dòng 1: sum := 0
  Dòng 2: product := 1
  Dòng 3: i = 1
  Dòng 4: sum = sum + 1
  Dòng 5: product = product * 1
  Dòng 3: i = 2
  Dòng 4: sum = sum + 2
  Dòng 5: product = product * 2
  ...

==============================================

📊 Case 1: Slice cho biến 'sum' tại dòng 7

🔪 DYNAMIC SLICE:
Slicing Criterion: <7, sum>

Các dòng ảnh hưởng đến biến 'sum':
+------+--------------------------------------------------+
| Dòng | Câu lệnh                                         |
+------+--------------------------------------------------+
|    1 | sum := 0                                         |
|    3 | for i := 1; i <= 5; i++                         |
|    4 | sum = sum + i                                    |
+------+--------------------------------------------------+

Số dòng trong slice: 3
Tổng số dòng thực thi: 12
Tỷ lệ rút gọn: 25.0%

💡 Giải thích:
- Các dòng 1, 3, 4 ảnh hưởng đến giá trị của 'sum'
- Dòng 5 (liên quan đến product) KHÔNG có trong slice
- Dynamic slicing giúp loại bỏ code không liên quan

========== FAULT LOCALIZATION - ĐỊNH VỊ LỖI ==========
